# WHAT IF ARTS BECOME LANGUAGE

**A Digital Curatorial Project · Responsive Web Design**

> *What if art could become a language?*

This project explores painting as a system of signs and questions the relationship between **language, meaning, perception, and silence**.

Inspired by Ludwig Wittgenstein's reflections on language and the limits of what can be said, the project presents six paintings through a digital exhibition interface.

### Concept

The project is structured around two interconnected themes:

#### I. THE INDECIBLE

These works approach the limits of expression.

Through black-and-white ink paintings, traces, surfaces, and disappearing forms, the works attempt to suggest what language cannot clearly articulate.

The image does not simply describe.
It indicates.

#### II. PRIVATE LANGUAGE

These works question whether meaning can exist without shared criteria.

Familiar visual references become blurred, fragmented, or ambiguous. The viewer is placed in the position of encountering an unknown language: fragments can be recognized, but the rules for interpreting them remain uncertain.

### Curatorial Logic

The exhibition treats the artworks as elements of a visual language.

| Linguistic Concept | Curatorial Equivalent        |
| ------------------ | ---------------------------- |
| Sign               | Visual element               |
| Vocabulary         | Individual artworks          |
| Grammar            | Relationships between works  |
| Meaning            | Viewer interpretation        |
| Ambiguity          | Unstable visual signs        |
| Silence            | The limits of representation |
| Context            | Exhibition structure         |

The website therefore functions not only as a gallery, but also as part of the conceptual project: **the digital interface becomes another layer of communication between artwork and viewer.**

### Design

The interface follows a minimalist black-and-white visual system inspired by the works themselves.

Key design principles:

* Minimalist editorial layout
* High-contrast monochrome visual identity
* Responsive grid-based artwork presentation
* Blurred photographic background
* Structured exhibition sections
* Mobile-friendly navigation
* Typography as part of the visual language
* Clear separation between artwork, description, and curatorial context

### Technology
